# 🎮 英语单词双人对战

一个单文件网页小游戏：**同步答题 + 单词消消乐**，适合课间学生互动、家教单词对战。学生用手机/平板/电脑打开链接即可玩，无需安装。

## 玩法

### ⚡ 同步答题
- 同一道题，两人左右分屏**各自输入答案并提交**，独立计时、互不抢答。
- 答对加预设分值（默认 +5，可自定义），答错不扣分；提交即显示本次用时。
- 全局倒计时结束未提交：不得分、不计用时。
- 全部答完结算：显示两人总分、胜负/平局、**平均答题用时**。

### 🧩 单词消消乐
- 两人各自点击中英卡片配对消除，先清空本盘者获胜，配对成功加分。

## 设置
- 单词自由录入（表格增删 / 批量粘贴 / 示例词库，**空单词会被拦截**）
- 出题方向：英→中 / 中→英 / 随机
- 单题全局倒计时、总题目数量、答对分值、语音朗读

## 在 GitHub 发布（手机可打开的链接）

1. 新建一个仓库（例如 `english-word-battle`），点 **Add file → Upload files**。
2. 把本文件夹里的 **`index.html`**（和 `README.md`）上传到仓库根目录。
3. 仓库 **Settings → Pages** → Source 选 `Deploy from a branch` + `main`，点 Save。
4. 等 1～2 分钟，游戏链接为：

   `https://你的用户名.github.io/english-word-battle/`

也可直接双击 `index.html` 在本地浏览器打开。

> 单文件网页，无任何外部依赖；上传 `index.html` 一个文件即可运行。
